# Sklep AZS ŚUM – demo koncepcyjne

Dwie wersje klikalnego demo sklepu z merchem dla KU AZS ŚUM, przygotowane do prezentacji dla klubu.

| Plik | Wersja |
| --- | --- |
| `sklep-azs-sum-demo.html` | Młodzieżowa: pastelowe kolory oparte na zieleni AZS i błękicie ŚUM (wersja rekomendowana) |
| `sklep-azs-sum-demo-elegancka.html` | Elegancka: głęboka zieleń, kamienne tła, klasyczny szeryf |

Jak obejrzeć: pobierz plik i otwórz go w przeglądarce (komputer lub telefon). Nie wymaga instalacji.

Co działa w demo:
- wybór koloru i rozmiaru produktu, ilość, koszyk,
- dostawa: odbiór na treningu, Paczkomat InPost, kurier,
- odliczanie do końca zbiórki zamówień.

Produkty, ceny i kolory są przykładowe, a zamówienia nie są realizowane. Gotowy sklep powstanie na Shopify po akceptacji klubu.
